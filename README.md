Main code created using Python 3.14.3 env in VS code.
The env had the following pips:
  1. Pytorch and PyTorch vision (Pytorch is for training our model and Pytorch Vision is an addon to handle images and videos. This version uses CUDA, installed using this link https://download.pytorch.org/whl/cu126).
  2. PyInput (Listens to inputs while not needing an open window like pygames).
